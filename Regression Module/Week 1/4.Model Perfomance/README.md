#  Regression Module: Model Performance

 **Module 4: Model Performance**! In this section, I explored how to evaluate machine learning models, understand performance metrics, and ensure models generalize effectively to real-world data.

---

##  Key Takeaways & What I Learned

Evaluating a predictive model goes far beyond fitting a line to data. The main focus of this module was learning how to test, quantify, and troubleshoot a model's ability to make accurate predictions on unseen data.

### 1. Model Accuracy & Performance Metrics
* Learned how to evaluate model performance using relevant evaluation metrics.
* Focused on understanding how metric choices impact decision-making and model reliability.

### 2. Common Challenges to Model Accuracy
* Explored common pitfalls that cause models to fail in production (e.g., overfitting, underfitting, and data leakage).
* Identified key indicators that signal when a model is failing to generalize.

### 3. The Train-Test Split
* Understood why splitting a dataset into training and testing sets is essential for preventing bias.
* Mastered implementing the **train-test split** in Python using `scikit-learn`.

### 4. Testing Model Performance
* Trained predictive models **strictly on training data** and evaluated their real-world capability using testing sets.
* Verified whether a model's predictions hold up when exposed to completely new inputs.
