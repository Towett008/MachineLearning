## Core Concepts Broken Down

### 1. Machine Learning vs. Artificial Intelligence
   Understanding the boundaries and connections between AI as a broader field and ML as a specific data-driven subset used to solve complex problems.

### 2. Regression vs. Classification
  **Regression:** Tasks focused on predicting continuous numerical values.
  **Classification:** Tasks focused on predicting discrete categories or labels.

### 3. Training and Assessing Models
  **Train-Test Split:** The practice of dividing data into a training set (to teach the model) and a testing set (to evaluate it). This ensures the model is assessed on unseen data to test its true performance.
  **Evaluation Metrics:** Utilizing specific statistical measures to check whether a model's predictions are accurate or need refinement.
