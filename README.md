## Repository Structure

The repo is organized into **three main modules**, each covering a distinct area of machine learning. Within each module, content is broken down further by **week**, and each week contains one or more **topics/submodules** (e.g., "Linear Models"). Every topic folder contains its own `Examples/`, `Exercises/`, and a `README.md` explaining what that topic covered.

**Folder breakdown:**
- **Module** (e.g., `Regression Module/`) — a major area of ML, containing multiple weeks
- **Week** (e.g., `Week 1/`) — a container for that week's topics/submodules
- **Topic/Submodule** (e.g., `Linear Models/`) — a specific concept taught that week, containing:
  - `Examples/` — worked examples and demonstrations from that topic
  - `Exercises/` — practice problems and hands-on tasks
  - `README.md` — a short summary of what the topic covered and key takeaways
